Hướng Dẫn Cấu Hình Microsoft OAuth

Đăng nhập chuyên nghiệp bằng tài khoản Microsoft (Outlook, Office 365, Azure AD).

1

Tạo App trên Entra ID

  • Truy cập Microsoft Entra admin center (trước đây là Azure AD).
  • Đăng nhập bằng tài khoản Microsoft.
  • Mở mục Applications > App registrations ở menu bên trái.
  • Nhấn New registration. Nhập tên ứng dụng (vd: PhimTop1).
  • Trong phần Supported account types, chọn Accounts in any organizational directory and personal Microsoft accounts (để hỗ trợ mọi tài khoản).
2

Cấu hình Redirect URI

  • Tại form đăng ký (hoặc sau khi tạo xong, vào mục Authentication).
  • Trong phần Platform configurations, nhấn Add a platform > Web.
  • Redirect URIs: Nhập URL được cấp trong Admin (vd: https://domain.com/api/auth.php?action=microsoft_callback).
  • Nhấn Configure (hoặc Register).
  • Ở màn hình Overview, copy Application (client) ID và lưu lại.
3

Tạo Client Secret

  • Truy cập mục Certificates & secrets ở menu bên trái.
  • Nhấn New client secret. Nhập mô tả (vd: Web App Key) và chọn hạn sử dụng (khuyến nghị: 24 tháng).
  • Nhấn Add.
  • QUAN TRỌNG: Copy ngay giá trị trong cột Value (không phải cột Secret ID). Đây là Client Secret của bạn, nó sẽ bị ẩn sau khi bạn tải lại trang.
  • Dán Client ID, Client Secret vào Admin. Tenant ID giữ nguyên common.
